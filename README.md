# 簪花游园 · 花影迷园

以《簪花仕女图》的工笔、绢底与矿物色为灵感的原创动作解谜游戏。新版入口为 `dist/index.html`，初版轻动作游园保留在 `dist/classic/`。

作者：王路。

[进入花影迷园](https://zan-hua-you-yuan.lithegrove1.chatgpt.site) · [旧卷游园](https://zan-hua-you-yuan.lithegrove1.chatgpt.site/classic/)

## 运行与完整项目

本仓库包含新版迷园、旧版轻动作游园、全部图片、两种格式的音乐、原始配乐生成脚本和测试。没有 CDN 或运行时外部依赖。

安装 Node.js 后直接运行，无需 `npm install`：

```sh
npm start
# 浏览器打开 http://localhost:3000
npm test
```

也可以用任何静态服务托管 `dist/`。

## 原创配乐《花影入梦》

106.67 秒、72 BPM、32 小节循环，以五声音阶旋律、丝弦拨奏、箫笛气声和少量铃音组成。四个八小节段落有呼应与变化。音乐在用户点击入园后播放，暂停时降低音量，切到后台时停止播放。

- `dist/assets/flower-dream.ogg`：浏览器优先格式。
- `dist/assets/flower-dream.mp3`：兼容格式。
- `dist/assets/music-score.json`：配器、速度和生成信息。
- `scripts/generate_music.py`：确定性合成与编配源码，不使用外部录音、采样或音乐 API。

重新生成配乐（仅生成时需要 NumPy、SciPy 和 ffmpeg）：

```sh
python -m pip install numpy scipy
python scripts/generate_music.py
```

## 进阶规则

每局生成一座 25 × 19 格迷园。穿行花墙，解开三座花亭的机关，取得牡丹、玉兰、莲花三印后，到月洞门按 E 出园。时间耗尽或花容归零则失败。园图显示已探索路径，三座花亭与出口的位置始终有标记。

三种难度：初游 7 分钟 / 6 花容，深园 5 分钟 / 4 花容，险境 4 分钟 / 3 花容。深园为默认模式。园号可复现同一迷宫，`?seed=41` 为一个示例。结算可重走同园，或生成新园。

### 三座机关

- 四时花序：四朵花的相对位置与邻接线索；生成器保证唯一答案。错答扣 12 秒，可取下重排。
- 九灯照春：点击翻转自身与上下左右相邻的灯，目标为九灯齐亮。初始局面保证有解，最短解为 4–6 步。
- 曲水流觞：旋转水渠，使水从左侧入口连通右侧出口；不用连通全部格子。

机关保存本局进度，离开后可继续。花露提示会揭示一条可执行线索。解开一座机关获得一枚花印、12 秒与 4 花露。解谜、奇遇与查看地图仍计时；暂停与帮助停止计时。

### 操作与资源

| 操作 | 按键 | 代价与作用 |
| --- | --- | --- |
| 移步 | WASD / 方向键 | 在通路中移动，墙与未开的花扉不可穿越 |
| 交互 | E | 进入机关、签亭、花扉或出口 |
| 挥扇 | J / 点击画面 | 12 花意；击退前方墨蝶，墙会阻挡挥扇 |
| 闪身 | K / Shift | 18 花意；沿方向最多掠过三格，落地后有短暂避伤 |
| 借花寻路 | L | 50 花意；七秒显示最近未解花亭的路线，三印齐全后指向出口；附近墨蝶暂时失神 |
| 饮露养容 | H / 养容按钮 | 6 花露回复一朵花容，满容时不消耗 |
| 园图 | M | 查看已经探索的路与目标位置 |
| 暂停 | P / Esc | 暂停当前环节；Esc 也可直接退出机关或园图 |

花意每秒恢复 8 点。花露可用于养容、提示（4 滴）或永久打开本局捷径花扉（5 滴）。墨蝶、荆棘受伤会失去一朵花容和 8 秒；荆棘会提前显出朱色预警。签亭一次性提供选择：稳取 4 花露，或抽签（50% 加 25 秒、30% 得 10 花露、20% 减 18 秒）。概率在选择前公开，不涉及真实货币。

触屏提供方向与动作按钮。保留减少动态选项，并遵循系统偏好。配乐默认开启，点击入园后开始播放。右上角可关闭音乐与音效，或单独调整背景乐音量；设置会保存在当前浏览器。
